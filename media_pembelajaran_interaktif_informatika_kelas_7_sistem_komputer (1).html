Apa itu Sistem Komputer?

3 Pilar Utama Komputasi Modern

Sistem Komputer adalah jaringan elemen terintegrasi yang terdiri dari perangkat keras, perangkat lunak, dan manusia yang saling bekerja sama untuk menerima, mengolah, menyimpan, dan menyajikan informasi digital.

1. Hardware (Perangkat Keras)

Komponen fisik elektronik yang dapat disentuh secara langsung oleh tangan.

Contoh: CPU, Keyboard, Monitor

2. Software (Perangkat Lunak)

Kumpulan program & instruksi digital tak berwujud fisik yang mengontrol hardware.

Contoh: Windows, MS Word, Chrome

3. Brainware (Pengguna)

Manusia yang memberikan instruksi, mengoperasikan, dan mengelola komputer.

Contoh: Programmer, User, Admin
Ketiga pilar ini bersifat mutlak. Komputer canggih tanpa program atau pengguna tidak akan dapat beroperasi!

4 Kategori Perangkat Keras (Hardware)

Klasifikasi berdasarkan peranan fungsionalnya

1. Perangkat Masukan (Input Device)

Berfungsi mengintruksikan atau memasukkan mentah data luar ke dalam komputer.

  • Keyboard: Mengetik teks, simbol, dan angka.
  • Mouse / Touchpad: Menggerakkan kursor & memilih menu GUI.
  • Scanner & Webcam: Mengambil data citra fisik menjadi berkas digital.
  • Microphone: Menginput data gelombang suara audio.
2. Perangkat Pemrosesan (Process Device)

Otak utama yang melakukan perhitungan matematis dan pemrosesan logika.

  • CPU (Processor): Pusat kendali utama (*Brain of Computer*).
  • RAM (Memory): Penyimpanan cepat data sementara saat sistem aktif.
  • Motherboard: Papan sirkuit penghubung seluruh komponen internal.
  • GPU / VGA: Pemroses sinyal gambar visual & animasi grafis.
3. Perangkat Keluaran (Output Device)

Menampilkan atau mengeluarkan hasil pengolahan data komputer ke manusia.

  • Monitor: Menampilkan visual antarmuka pengguna.
  • Printer: Mencetak berkas digital ke media fisik kertas.
  • Speaker / Headphone: Mengeluarkan suara/audio.
  • Proyektor: Memancarkan tampilan visual ke layar lebar.
4. Perangkat Penyimpanan (Storage Device)

Penyimpan data berkas secara permanen (*non-volatile*) walau listrik mati.

  • SSD / HDD: Media penyimpanan utama sistem & file pengguna.
  • Flashdisk (USB Drive): Penyimpanan portabel berbasis flash memory.
  • MicroSD / SD Card: Kartu memori untuk kamera & smartphone.

Klasifikasi Perangkat Lunak (Software)

Sistem Operasi vs Program Aplikasi

A. Sistem Operasi (Operating System / OS)

Software tingkat pertama yang bertindak sebagai fondasi pengelola hardware dan wadah eksekusi program aplikasi.

Microsoft Windows PC / Laptop
macOS & iOS Apple Ecosystem
Android OS Smartphone
Linux (Ubuntu/Debian) Open Source
B. Program Aplikasi (Application Software)

Software spesifik yang dibuat untuk mempermudah pekerjaan khusus manusia dalam kehidupan sehari-hari.

Pengolah Kata (Word Processor): Microsoft Word, Google Docs, LibreOffice
Pengolah Angka (Spreadsheet): Microsoft Excel, Google Sheets
Perambah Web (Web Browser): Google Chrome, Mozilla Firefox, Microsoft Edge
Desain Grafis & Presentasi: Canva, Adobe Photoshop, MS PowerPoint

Siklus Data & Antarmuka Komputer

Bagaimana Informasi Berjalan & Diinteraksikan

Diagram Siklus Pengolahan Data (IPO + S)

1. INPUT

Pemasukan data mentah via keyboard/mouse

2. PROCESS

CPU mengolah dan menghitung logika

3. OUTPUT

Hasil disajikan pada layar / cetakan

4. STORAGE

Penyimpanan permanen di SSD / HDD

Bentuk Interaksi Manusia dan Komputer (IMK):

GUI (Graphical User Interface)

Interaksi visual paling umum berbasis ikon grafis, menu, tombol, dan kursor mouse.

CLI (Command Line Interface)

Interaksi berbasis baris perintah teks instruksi (seperti Command Prompt atau Terminal).

Audio / Perintah Suara

Perintah langsung suara menggunakan asisten kecerdasan buatan (Siri, Google Assistant).

Sentuhan (Touchscreen)

Interaksi gestur jari langsung pada layar sentuh smartphone atau tablet.
